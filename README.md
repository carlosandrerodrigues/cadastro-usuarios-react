
# Cadastro de Usuários - React

Projeto simples em React para cadastro, listagem e remoção de usuários.

## Tecnologias
- React
- JavaScript
- CSS

##  Funcionalidades
- Cadastrar usuários
- Listar usuários
- Remover usuários
- Layout responsivo
 ## Objetivo

Projeto criado para fins de estudo e prática com React, com foco em componentes,
estado, props e consumo de API.
## Aprendizados

- Criação de componentes React
- Uso de useState e useEffect
- Comunicação entre componentes (props)
- Consumo de API com fetch
- Estrutura de projeto React

## Como rodar o projeto
```bash
npm install
npm run dev
